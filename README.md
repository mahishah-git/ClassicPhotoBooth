# ClassicPhotoBooth
A vintage-style photo booth built using **HTML, CSS, and JavaScript**.

The project uses the device camera to capture photos, arranges them into a vintage photo strip, and allows the final result to be downloaded and saved.

## Features

- Capture photos directly using your camera
- Countdown before each photo
- Capture multiple photos for one photo strip
- Vintage-inspired photo strip design
- Download the final photo strip
- Responsive layout
- Vintage aesthetic with custom CSS effects

## Built With

- **HTML5** – Structure and layout
- **CSS3** – Styling, animations, and vintage effects
- **JavaScript** – Camera access, countdown, photo capture, canvas processing, and downloads
- **Canvas API** – Generates the final photo strip
- **MediaDevices API** – Accesses the user's camera
